# Relay Core frontend prototype

Vue 3 and Frappe UI 0.1.261. Uses sample data only; changes reset on reload. No backend or provider calls.

Run `npm install`, `npm run build`, `npm run preview`. Generate a standalone HTML file after building with `python3 package-preview.py`.

Inbox, team editing and a fixed flow diagram are implemented for design review. Arbitrary flow creation and execution remain future work. This prototype is not a production communication client.
